What's inside

Built already works in the codebase today. Planned is scheduled for the launch release or shortly after.

Auth with JWT Built

Signup/login with BCrypt, short-lived JWT access tokens and rotating refresh tokens stored in Redis.

Multi-tenancy Built

Tenant-scoped data by design: tenant_id on business tables, cross-tenant access returns 404, workspace switching.

Roles & invites Built

OWNER / ADMIN / MEMBER with method-level security. Single-use, expiring, email-bound invitations.

CLAUDE.md & AGENTS.md Built

Architecture, commands, conventions and do/don't rules that Claude Code and Codex read before they edit.

10 subagents & 10 skills Built

Subagents such as spring-backend, vue-frontend, code-reviewer, auth, migration and security-auditor, each with explicit "Done when" checks. Skills such as add-crud-entity, add-flyway-migration and add-vue-page that walk the agent through the change step by step.

Docker & CI Built

docker compose for Postgres, Redis, backend and frontend. GitHub Actions runs tests, including Testcontainers integration tests.

Subscription billing Built Creem adapter planned

Hosted checkout, signature-verified and idempotent webhooks, a billing page and plan-based feature gates (unpaid workspaces get HTTP 402). The current integration targets Lemon Squeezy; a Creem provider is being added.

Admin console Built

Platform admin views for users, tenants and subscriptions, with account disabling and an audit log.

Codex parity Built

How it works

From clone to your first agent-built feature in minutes.

Run the stack

One command starts PostgreSQL, Redis, the Spring Boot API and the Vue app.

Open your agent

Claude Code or Codex reads CLAUDE.md / AGENTS.md and learns the layout, commands and rules.

Ask for a feature

Skills like add-crud-entity walk the agent through migration, entity, API, tests and UI the same way every time.

Review and ship

The code-reviewer subagent checks the diff and CI must pass before you merge.
