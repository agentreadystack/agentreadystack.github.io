What's inside

Built already works in the codebase today. Planned is scheduled for the launch release or shortly after.

Auth with JWT Built

Signup/login with BCrypt, short-lived JWT access tokens and rotating refresh tokens stored in Redis.

Multi-tenancy Built

Tenant-scoped data by design: tenant_id on business tables, cross-tenant access returns 404, workspace switching.

Roles & invites Built

OWNER / ADMIN / MEMBER with method-level security. Single-use, expiring, email-bound invitations.

CLAUDE.md & AGENTS.md Built

Architecture, commands, conventions and do/don't rules that Claude Code and Codex read before they edit.

Up to 10 subagents & 10 skills Built

Subagents such as spring-backend, vue-frontend, code-reviewer, auth, migration and security-auditor, each with explicit "Done when" checks (Starter: 8 + 8; Pro/Team add devops, security-auditor, add-cache and add-env-var). Skills such as add-crud-entity, add-flyway-migration and add-vue-page that walk the agent through the change step by step.

Docker & CI Built

Every plan: docker compose for local Postgres + Redis and Testcontainers integration tests. Pro/Team deployment kit: production Docker images, VPS/Render/Fly configs and a GitHub Actions pipeline.

Subscription billing Built

Hosted checkout, signature-verified and idempotent webhooks, a billing page and plan-based feature gates (unpaid workspaces get HTTP 402). Creem is built in (checkout, webhooks, license-key validation and automatic GitHub repo invites); Lemon Squeezy remains available as a legacy option via BILLING_PROVIDER.

Admin console Built

Platform admin views for users, tenants and subscriptions, with account disabling and an audit log.

Codex parity Built

Claude Code and Codex share one set of rules and skills, kept in sync by a script that CI checks, plus a Claude Code ↔ Codex mapping doc.

How it works

From clone to your first agent-built feature in minutes.

Run the stack

One command starts PostgreSQL, Redis, the Spring Boot API and the Vue app.

Open your agent

Ask for a feature

Skills like add-crud-entity walk the agent through migration, entity, API, tests and UI the same way every time.

Review and ship

The code-reviewer subagent checks the diff and CI must pass before you merge.
